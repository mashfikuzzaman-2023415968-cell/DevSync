## Newcomers and role assessments

A newcomer (fewer than three finished projects) can only bid for a role after passing a role
assessment for it: the same assessment, built from your project's roles and requirements, for
everyone bidding for that role. In **Bids**, "Why eligible" shows the result, for example
"Role assessment: 78, passed; strongest: API design; weakest: testing". You never see answers,
and the result is a competency check, not completed work: the team is still chosen on
everything else Algorithm 1 checks.
